# Botanical text box borders

The 尤加利叶, 薰衣草 and 樱花枝 text box borders (`eucalyptus-*`, `lavender-*` and `sakura-*` WebP files) are cut from public-domain botanical plates. `npm run build:text-border-plates` keys the paper out of each sprig and arranges the sprigs into seamless edge strips and corners. The full-resolution plates are kept in `frontend/text-border-sources/` and are not served.
