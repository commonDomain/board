# Built-in image backgrounds

The seven new wallpapers were generated with the built-in ImageGen tool for a quiet, wide canvas backdrop. The generated 1672 × 941 sources were resampled to 2560 pixels wide and delivered as WebP; the resampling improves display sizing but does not add source detail. A light color wash is applied at render time to keep board content legible. The other five backgrounds are public-domain scans or records and preserve their source pixel dimensions.

The reference frame dimensions in `public/app.js` are at most one quarter of each bundled image's dimensions. The seven new images have an approximately 16:9 ratio for common desktop viewports. Image backgrounds are drawn with `background-size: cover` anchored to the bottom edge, so they fill the viewport without distortion and re-crop when the window aspect ratio changes.

## Preview derivatives

`<name>.preview.webp` are 360px-wide WebP derivatives generated by `npm run build:backgrounds`. The background menu swatches are roughly 110 × 60 CSS pixels. All twelve previews total about 88 KiB, avoiding full-size image downloads when the menu opens. Re-run the build script after replacing a source image.
