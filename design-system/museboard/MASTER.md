# Museboard 局部界面设计规范

更新：2026-10-04。以当前运行界面和源样式为基线。本规范替代旧文档中的青绿主色、橙色 CTA、Plus Jakarta Sans 和营销页面布局建议。

## 两种模式的身份

画板保留紫色、玻璃表面、大圆角、空间布局和与触发点关联的形变动画。笔记保留浅灰工作区、白色正文、自由页面、功能选项卡和多标签。共享控件组织与反馈规则；两种模式分别提供颜色、材质、圆角和阴影。

源文件：`frontend/styles/foundation.css`、`frontend/styles/notes-theme.css`。不得直接维护构建产物 `public/styles.css`。

| 用途 | 画板 | 笔记 |
| --- | --- | --- |
| 强调 | `--accent: #6957f5` | `--nt-accent: #6350d8` |
| 悬停/焦点 | `--accent-strong: #5744eb` | `--nt-accent-hover: #5140bf` |
| 正文 | `--ink: #171922` | `--nt-ink: #252833` |
| 辅助文字 | `--muted-strong: #4c5260` | `--nt-muted: #626976` |
| 工作区 | `--canvas-bg: #f2f4f7`，沿用背景选择 | `--nt-bg: #f5f6f8` |
| 选中 | 原紫色半透明选中面 | `--nt-selected: #eeebfc` |
| 输入边界 | `--control-line: #858b98` | `--nt-control-line: #858b98` |
| 危险 | 沿用画板危险色，文字复核对比度 | `--nt-danger: #b83045` |
| 圆角 | 原 8/11/15/20/26px 梯度 | 控件 8、菜单 10、弹窗 14px |

字体沿用 `--font-ui` 的 Inter / 系统字体 / Microsoft YaHei 回退。不加载新的网络字体，不改笔记正文或用户对象的字号。

## 局部尺度

- 间距使用 4、8、12、16、24px。图标与名称 8px，同组 4–8px，组间 16px。
- 菜单内边距 6–8px，属性面板 16px，编辑弹窗 24px，窄屏 16px。
- 控件和菜单 13px / 450–500；辅助信息 12px；组标题 600。弹窗标题保留 17–18px。
- 普通图标 16px，主要工具原尺寸保持。数字控件使用等宽数字。
- 常驻区域依靠边界；浮层沿用菜单阴影和弹窗阴影，不叠加光晕。
- 粗指针目标至少 44×44px。文字对比度目标 4.5:1，关键边界/焦点目标 3:1；玻璃面板按实际背景复核。

## 控件与浮层

默认、悬停、按下、选中、焦点、禁用、加载分别表达。焦点使用两像素紫色轮廓；选中提供背景和 `aria-pressed`。多选不同数值显示“混合”，加粗采用 `aria-pressed="mixed"`。修改只作用于适用且可编辑的对象，整组只占一次撤销。

禁用原因通过 `data-disabled-reason` 和 `aria-description` 提供；菜单就地显示，触屏功能区提供可见提示。加载保持尺寸并阻止重复执行。工具提示采用委托事件：鼠标延迟 400ms、键盘聚焦立即显示；快捷键仅显示现有绑定，按平台使用 Ctrl / ⌘，不扫描编辑文档。

笔记菜单支持 `{label, run, icon, group, danger, disabled, reason, shortcut}`，兼容 `[label, run]` / `[label, run, metadata]`。危险状态只取显式字段，不从名称推断。

桌面菜单距触发控件和视口边缘 8px；过多内容内部滚动。跟随窗口、滚动、visualViewport 定位。粗指针、可视宽度不大于 1100px 时使用底部面板，复杂表单保持对话框。

上下箭头、Home、End 跳过不可用项。菜单允许外部关闭；表单遮罩不丢弃输入。Esc 关闭当前浮层，输入法组合期间不触发关闭。移除时清理定位帧、动画和监听；编辑上下文仍有效时恢复触发点或选区。

危险动作独立分组；确认标题说明对象与结果，按钮写明动作。必填错误就地展示。现有保存失败、冲突、副本恢复入口继续保留。

## 动效

| 场景 | 时长与约束 |
| --- | --- |
| 按钮颜色/边界 | 120ms，动作立即执行 |
| 笔记菜单/弹窗 | 140ms，位移最多 4px |
| 笔记抽屉 | 180ms，保留进入方向 |
| 画板形变弹出 | 保留现有 360–440ms 与触发点关联 |
| 画板其他局部过渡 | 180–220ms |
| 来源定位 | 沿用一次强调，约 1600ms 消退 |

关闭立即释放点击与焦点，连续开关取消旧动画。延续各模块原有动画偏好处理，不新增全局策略，不重建编辑器实现动画。

## 业务边界

复用原生 ES 模块、现有 DOM、编辑器、定位模型与操作入口。辅助状态只在组件生命周期内；不改变内容坐标、数据格式、权限、保存、协作或引用关系。不新增 UI 框架、服务端接口或命令中心。

本轮不包含斜杠菜单、大纲、演示、AI 和暗色主题。细则见 `pages/canvas.md`、`pages/notes.md`。
