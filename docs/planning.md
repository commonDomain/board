# 现有画布与笔记中的规划

规划沿用 Museboard 的画布、自由笔记、菜单、字体和紫色强调色。顶部仍只有画布、笔记两个模式；新增模块位于 `frontend/planning`，编辑器和保存流程继续使用原有实现。

## 操作

- 在画布顶栏或笔记左侧点击“规划”，打开当前内容的紧凑任务列表；切换“我的任务”“全部可访问规划”，或筛选本周到期、逾期、阻塞和归档任务。关闭面板保留画布视角、笔记滚动、输入和选区。
- 空白处右键插入规划清单、看板或日历。组件标题栏单击选中、拖动移动、双击进入规划设置；画笔等模式下也可直接操作，无需切换工具。标题栏提供“编辑规划”和删除组件按钮，调整尺寸仍用原有手柄；组件内切换视图使用同一批任务。
- 桌面规划侧栏可拖动标题调整位置，点击“复位位置”回到默认位置；手机继续使用固定抽屉。
- 鼠标位于画布中的规划标题、任务或按钮上时，Ctrl/Cmd＋滚轮沿用画布缩放，缩放中心跟随鼠标；普通滚轮滚动规划列表或看板，与表格预览的滚轮行为一致。
- 鼠标中键双击规划框（包括内部任务／按钮）适配放大到可见区域，画布再次中键双击同框可返回之前视角；笔记中也支持适配放大。单击规划框标题仅选择或移动，不显示通用右侧属性栏。点击具体任务的标题或行内空白才打开任务详情；切换任务时只保留一个详情面板，点击外部收起，已编辑输入仍保留，未编辑的查看不会生成草稿。
- 右键便签、文字、明确选中的脑图节点或单项笔记待办，选择“加入规划”。预览勾选项及标题后确认；多选不会递归转换整个脑图。
- 脑图节点右键选择“关联已有任务”，可连接当前画布／笔记中的具体规划任务；多个节点可指向同一任务。使用原生连接线和智能路由，端点落在具体脑图节点与清单任务行、看板卡片或日历任务上；画布继续使用现有连线工具编辑样式、标签、端点及删除。未在当前日历月份展示的任务有独立关联入口；已有节点关联可通过“添加任务连线”补建原生线。
- 已关联节点的状态与规划双向同步：在规划中修改会更新脑图；点击脑图状态标签，明确选择待办、进行中、阻塞或完成，保存后更新其他引用和进度。父任务状态与子任务进度独立。
- 任务详情点击“脑图拆解”，每行填写一个执行步骤，一次生成最多 30 个普通子节点。只有父节点关联原任务并连接到规划；子节点不自动创建或关联任务，可直接编辑、继续添加分支，不改变规划任务数量和进度。拆解需在规划所属画布／笔记中执行。已有任务及其关联保留；需要任务关联时，可手动使用“加入规划”或“关联已有任务”。
- 侧栏新建空白规划时只建立宿主关系；“插入当前内容”再放入组件。个人周计划、小团队项目、创意交付模板直接插入组件。
- 在清单、侧栏或看板列中添加任务：Enter 连续添加并保留输入框，点击“添加”结束本次录入，Esc 关闭并保留输入；中文输入法组词期间不提交。可识别空格分隔的“明天”、日期、`@我`、`!高`、`截止:2026-10-12`；识别结果可预览、关闭，也可用双引号保留字面标题。多行粘贴进入最多 100 项的批量预览。
- 侧栏可搜索任务标题、阻塞说明和成果文本；搜索与查看范围、任务筛选组合生效。完成率以进度条显示，任务卡片显示状态、日期、优先级和负责人。手机抽屉限制背景操作，关闭后恢复原焦点。
- 看板跨列拖动改变状态，同列拖动调整顺序；各列可收起，完成列超过 10 项时默认收起。日历区分执行安排和截止日期，支持按日添加、同日超量展开；小屏默认使用日程清单。日期筛选以 `Asia/Shanghai` 判断，本周从周一开始。
- 关联内容使用任务详情修改统一标题和状态；“编辑来源正文”继续使用原有文字编辑器。来源中的其他段落、脑图结构、位置及样式仍由原编辑器保存。解除关联保留最新标题与状态，并恢复普通内容。
- 手机通过内容的“更多内容操作”、脑图的“更多节点操作”，或画布原有“更多”菜单访问相同功能；规划侧栏为可关闭抽屉，看板横向滚动。
- 规划设置中填写目标、完成标准、成果数值与单位，添加并手动确认里程碑、记录复盘。任务完成率排除已归档任务，与成果数值独立展示。
- 清单、看板和侧栏任务行提供删除按钮，任务详情内也可删除；日历中的任务点击进入详情。删除均须在界面中确认。里程碑可编辑名称和完成标准，也可删除；删除里程碑保留任务并清除所属里程碑。复盘记录可单独删除。

## 保存、权限与生命周期

`taskRef` 指向一项权威任务；`planRef` 只引用规划，组件视图配置保存在原内容中。复制引用继续指向原任务，不重复统计；任务详情中的“复制为新任务”生成独立任务。

账号规划文档保存到现有 SQLite 的 `planning_documents`，其中任务和里程碑各有独立版本；`planning_operations` 保存带用户、`opId` 的操作回执。游客文档、回执和待提交草稿保存到独立 IndexedDB `muse-planning`。写入检查实体版本，成功提交后广播失效通知；断网、锁冲突和版本冲突保留本地草稿。侧栏可重试原操作，或检查原草稿后按当前版本重新应用。

每份规划继承唯一宿主的可见性和编辑权限，沿用原有画布及笔记编辑锁。负责人需为本人或当前共享组成员，且能访问宿主。来源权限另外检查；分享规划不会扩散其他来源的访问权限。无权访问的引用显示占位，权限撤销后刷新移除缓存中的不可访问规划。

关联先幂等建立任务，再通过原内容保存流程写入引用。画布等待原同步队列确认，笔记等待原保存流程完成；关联失败时任务保留在规划中，标记“来源待关联”，可从任务详情重试。

删除组件保留规划和任务；删除来源只断开来源关系。删除画布或将宿主笔记移入回收站后归档相关规划。归档规划只有所有者可见，可在侧栏重新绑定自己的可编辑画布或笔记后恢复。恢复笔记不会隐式恢复规划。关闭功能开关保留规划记录，旧内容继续使用原有编辑器。

删除任务释放 2,000 项活动任务容量，正文快照保留 30 天用于恢复。侧栏回收站可恢复或永久清理；恢复不会自动重新建立父子关系、依赖或修改其他宿主的来源。永久清理后保留任务标识和操作摘要，正文不可恢复。规划所有者可归档、移入回收站、恢复或永久清理整份规划；恢复规划先进入归档，再明确迁移到自己的可编辑内容。500 份配额仅计算活动规划。

服务端在维护任务中清理超过 30 天的回收站正文；游客在打开规划时清理。回执使用 SHA-256 摘要，既有明文规划回执在服务启动／游客规划加载时迁移。清理不删除外部导出文件、历史数据库备份、来源原文或尚未放弃的编辑草稿。

拆解以单个带版本校验的操作登记父节点来源，不创建子任务；脑图来源与父节点原生连接线另走原画布／笔记的保存流程。来源尚未保存时保留“脑图拆解”草稿，可在原宿主侧栏重试，使用同一批节点标识继续完成，不重复创建节点或连线，并保留已有分支编辑和手动关联。旧版本已经生成的任务不会被自动删除，尚未提交的旧拆解草稿按普通子节点方式继续。删除父任务保留已有子任务并解除父子关系；删除任务使原生端点悬空，沿用连线工具重新连接或删除。删除连线不影响任务引用及状态同步，刷新不自动重建。拆解复用自定义脑图创建及智能布局，节点按字体字号换行并扩展高度，脑图外框随内容扩展。

删除关联脑图后，新关联确认会清除当前有权校验、确实已删除的旧对象／节点引用。重试拆解会补回原任务的正向来源和脑图节点的反向引用，先持久化脑图，再确认关联；笔记中扩展已有脑图也遵循此顺序。已生成但关联失败时可在侧栏草稿中“重试提交”，不会重复创建同一批任务或连线；不同任务占用的节点不会被覆盖。

删除关联脑图会同时删除连接到该脑图的原生／旧版连接线，并移除任务中的对应来源引用；任务本身及其他来源保留。画布和云端笔记在来源保存事务中清理引用，失败或版本冲突会回滚；游客数据也会清理尚未确认的旧来源。撤销删除恢复脑图、原连接线和有权恢复的任务引用，重做再次清理。关联连接线已锁定时，需先解锁再删除，避免留下无法清理的线。删除规划任务仍沿用原生端点悬空行为，与删除脑图的清理规则分别处理。

接口：`GET /api/plans/capabilities`；账号使用 `GET/POST /api/plans`、`GET /api/plans/:id`、`POST /api/plans/import` 和 `POST /api/plans/:id/operations`。目录支持 `limit/cursor/summary/versions`，分页期间目录变更会触发客户端重取。写接口使用现有账号会话、CSRF、实体版本和真实宿主锁；批量操作整体提交或整体回滚。

笔记备份 v2 包含可访问的规划正文；云端摘要先下载为完整文档再导出，网络或正文缺失时不生成冒充完整的备份。导入可选独立副本或继续引用原任务，兼容 v1。独立副本重映射规划、任务、里程碑、复盘、宿主、节点与原生连线；只携带导入内容内部的来源，不继承共享权限，其他成员的负责人身份置空。游客画布和账号笔记导入在服务端与规划使用同一事务；游客笔记与规划仍分属两个本地数据库，中断时原副本保留。

今日安排、下一步、等待事项、重点、进行中数量提醒、前置依赖、成果验收和复盘转任务帮助形成执行闭环。常用筛选、舒适／紧凑密度、停靠、宽度和位置按当前设备账号保存。应用内提醒默认关闭，只在应用打开时提示。任务状态、日期、负责人可行内修改，短时间内可撤销；更多菜单提供选择、上移／下移、批量修改与删除。详情低频属性可折叠，输入可关闭后继续编辑。

普通单字段修改可合并其他窗口对不同字段的更新；同字段冲突保留草稿供核对，来源、宿主、依赖和排序等结构变更不自动合并。服务器提交成功与本地缓存失败分别提示。来源校验区分待关联、读取失败及无权访问；列表摘要载入时显示“正在载入”。账号切换清除上一账号的选择、撤销和返回入口。

## AFFiNE 借鉴范围

参考 [AFFiNE 官网](https://affine.pro/) 的文档、白板和数据库在同一工作区中承载规划的方式，并检查 [AFFiNE 源码](https://github.com/toeverything/AFFiNE) 快照 `6bb64575b1013d64df0382375541901244e8052d` 中的数据库、多视图和看板交互。对应目录包括 `blocksuite/affine/blocks/database/src`、`blocksuite/affine/data-view/src`。

本实现借鉴内容内管理、同一数据切换视图、行内添加、拖动改变状态和原地属性编辑；规划侧栏适配 Museboard 已有的两个编辑器。没有移植 AFFiNE 代码，没有引入 BlockSuite 或新增依赖。内部任务引用不进入 XMind 的同步比较或结构化属性补丁。首期未加入 AI、甘特图、自动排期、周期任务和外部提醒。

## 启用与验证

1. 使用 `npm run backup:now` 备份当前 SQLite 和资源。
2. 设置 `PLANNING_ENABLED=1`，构建并启动现有服务。默认值为 `0`，关闭时数据保留。
3. 运行 `npm run build`、`npm run check` 检查构建、语法和模块依赖。
4. 在对应设备和部署环境中检查规划创建、三种视图、来源关联、保存与权限流程。

项目已移除自动测试脚本、测试截图与历史核查产物。
