# 缩放控件设计方案

这组概念图使用 OpenAI ImageGen 生成，统一采用 MuseBoard 深色玻璃拟态界面、右下角悬浮位置、紧凑尺寸和清晰的缩放层级。

1. `01-minimal-pill.png`：极简横向胶囊，减号、百分比、加号三段式布局。
2. `02-segmented-controls.png`：紧凑分段方形按钮，百分比作为独立读数。
3. `03-radial-control.png`：圆形径向缩放控件，适合强调空间操作感。
4. `04-vertical-stack.png`：纵向堆叠，适合窄屏与移动端安全区。
5. `05-slider-control.png`：微型滑杆搭配加减按钮，适合连续调节。
6. `06-split-capsule.png`：超紧凑分裂胶囊，百分比区域可展开预设。
7. `07-accessible-controls.png`：无障碍优先，强化触控面积、对比度与当前倍率读数。
