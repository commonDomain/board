# 专业连接系统：实现与验证记录

连接保存在原有 `connector` item 中，复用撤销、WebSocket 队列、IndexedDB 和导出流程。新增实现没有替换画布框架。

## 模块

| 文件 | 职责 |
| --- | --- |
| `public/connector-core.js` | 版本化端点、稳定单元格身份、Unicode 文字范围映射、失效绑定和几何纯函数；浏览器和服务端共享 |
| `public/connector-router.js` | 确定性正交路由、局部约束、曲线、圆角和有预算的退化路径 |
| `public/connector-worker.js` | 将避障计算移出主线程 |
| `public/connector-ui.js` | 创建、重绑、文字选择、内容测量、独立 SVG 层、标签、样式、关系导航及冲突草稿 |
| `public/connector.css` | 命中区域、临时控件、触控尺寸、低缩放显示及减少动画 |
| `backend/server.js` | 字段版本校验、文字及关联原子更新、旧客户端保护、迁移快照 |

## 交互

- 连接工具支持点击起点后再点终点，也支持从临时手柄拖出。目标按实际指针坐标识别，支持画框、脑图节点和表格单元格。
- 两端均可拖动重绑。文字选区使用显式工具条确认；失效端点通过“更多 → 起点／终点重绑为文字”恢复，保留同一连接的标签、样式和路径。
- 拖动折线中段保存局部约束；经过点可移除。锁定折点保存当前经过点并停用拖动，端点移动时仍会重算；恢复自动路径清除约束。曲线保留控制柄。
- 新连线默认使用“智能”线型，结合两端元素类型、距离、方向、相邻连线的手选线型和中途遮挡，在直线、圆角折线、曲线之间动态选择；长距离但近乎水平或垂直且无遮挡时优先直线，并在临界角度保持原有判断，避免拖动时反复切换。便签或文本错位连接优先曲线，表格、画框、流程图形以及被其他对象挡住的路径优先折线；关联连线的手选样式仅在当前几何形态适合时影响选择。旧连接仍保持原有线型。直线不显示折点拖动手柄，智能线型若需手调折点可先切为具体线型；切换线型时清除旧线型约束。创建预览使用新连线的线型。正交线的起点和终点引线可分别设为 0、8、16、24、32 或 48 画布单位，0 表示不保留短弯钩。
- 选中连线的“更多”按样式、路径与引线、端点、方向与关系、连线工具与画布分组；分组在右侧玻璃面板打开，顶部返回按钮回到目录。不可用的路径和端点操作隐藏或禁用。未选中连线时，连线工具栏可预设新线线型、标记、颜色及工具偏好。下拉和侧边面板沿用画板的透明毛玻璃样式；菜单显示操作说明，设置改变后给出提示。
- 标签显示在线条上方的气泡中，字号随画布缩放调整并限制屏幕显示大小。再次点击工具栏“标签”会回填第一个已保存的标签；双击线条或在样式菜单中选择“新增标签”可保留多标签。仍支持方向标记、批量样式及单步粘贴样式。自由端点可以创建便签、形状或同类文本，创建和绑定合为一个撤销步骤。
- 查看关联默认展示直接入线和出线，支持主动再展开一层。折叠代理保持真实目标 ID，拥挤时显示数量入口；隐藏目标不展示内容。
- 跳线默认关闭，作为画布共享设置同步和持久化，支持撤销重做；更新背景不会覆盖跳线设置。默认不共享干线。普通连接位于内容下方，内部末端单独绘制并对文字留空。

## 数据与兼容

`connectorVersion: 1` 与文档版本、同步队列版本独立。主要字段为 `source`、`target`、`route`、`style`、`labels`、`relation` 和 `fieldVersions`。未知的 item 顶层字段随原对象保留。

文字锚点包含稳定 ID、Unicode 码点范围、引用原文、前后文和内容版本；格式变化不移动范围。前方增删映射范围，内部插入纳入片段，边界外插入不纳入；整段删除进入 `orphan`，不猜测同名文字或自动改连整体对象。

同步提交使用 `connectorCapabilities: 1`。端点、路线、标签、样式按字段提交并校验预期版本；文字更新校验内容版本。冲突保留本地草稿，并提供下载和恢复文本副本入口。自动折点为派生缓存，Worker 请求版本用于丢弃过时计算。

服务端报告 `CONNECTOR_VERSION` 时，客户端取消手势、切换平移并进入兼容只读状态，禁止继续入队、发送操作、保存或覆盖本地快照。原有连接和冲突草稿保持可读，更新客户端后重新打开画布。此次按用户要求直接启用，不引入灰度开关或分批启用机制。

旧连接维持原有直线外观。第一次写入新版连接时，服务端在同一事务中保存升级前快照；已有新版连接的画布拒绝无能力标记的旧客户端写入。升级前快照保存在数据库的 `connector_migration_archives` 表中。

## 性能实测

2026-09-05，Windows，Intel i5-12400，Node 24.15.0，Chrome 152.0.7977.75，视口 1440×1000。90 次目标移动、局部连接更新及下一帧预览采样：

| 对象 / 连接 | 挂载元素 | 更新 CPU P95 | 预览 P95 | 观察到的 >50ms 长任务 |
| --- | ---: | ---: | ---: | ---: |
| 1,000 / 2,000 | 246 | 11.0ms | 26.6ms | 0 |
| 2,000 / 1,000 | 145 | 2.0ms | 9.7ms | 0 |

这些结果针对视口裁剪后的场景，不代表所有对象同时可见、所有设备或所有网络。

## 最终检查与环境限制

真实 iOS/Android 的系统文字选区、输入法、多指导航及真实 Safari 尚无设备实测证据。当前环境没有提供移动设备，WebKit 运行时不能替代 iPhone/Safari；这部分仍是未完成的真机验收，不宣称全部测试完成。灰度启用已按用户要求从交付范围中取消。

避障单次最多使用 64 个候选障碍和 6,000 个搜索节点；超预算或 Worker 不可用时显示可编辑退化路径及警告。图片热点跟随现有缩放及旋转；现有编辑器没有裁剪工作流，因此未验收未来裁剪状态。
