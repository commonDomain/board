# 跨设备快传与五子棋

两项功能从画布左侧工具栏进入：「快传」直接打开，「游戏」使用手柄图标，点击下拉菜单选择「五子棋」。手机端同样可用。快传只要求生成配对二维码的设备登录，另一台设备免登录双向收发；五子棋需要登录并按画布隔离。功能不依赖编辑图层或画布编辑锁，不进入画布保存和撤销队列，独立模块失败不影响画布启动。

## 快传

1. 任意一台设备登录网站，打开快传，点击「生成配对二维码」，不必先选择文件。
2. 另一台设备扫码，自动进入独立的双向快传页，无需登录或选择游客模式。配对只允许一台其他设备加入，成功后隐藏二维码，第三台设备不能重复加入。
3. 配对后双方都可以「选择文件 → 发送文件」，另一方确认来源后点击「保存文件」或「拒绝接收」。同一连接可以连续、交替双向发送；一次只处理一个文件，同时发送会提示忙碌，可稍后重试。
4. 「取消当前文件」保留连接，可继续传输；「断开连接」、关闭面板、退出/切换账号、隐私锁都会结束配对。两端需保持在线、页面打开、设备亮屏。

采用 WebRTC 浏览器直传：文件内容不经过应用服务器，不写服务器临时目录、资产库、数据库或备份，也不解析、预览、解压或执行文件。服务器只在内存中短暂交换加密 SDP 连接描述和授权状态，不接收文件名、文件大小或文件密钥。普通登录、限流等基础设施仍可能写入常规账号/请求记录，不能将本功能描述为“服务器完全零写入”。

- 每次配对使用新的随机根密钥。信令使用 HKDF 独立派生密钥加密并认证连接指纹；控制消息按发送方向派生独立密钥，附带严格递增序号，拒绝反射、重放和乱序。文件名、大小、每文件随机密钥都在该加密直连控制通道中传递。每个文件使用新的 AES-256-GCM 密钥、随机 IV 前缀和独立数据通道，不在双向/重复发送时复用文件加密材料。
- 链接密钥只在 URL 片段中传递，页面加载后从地址栏移除，不写本地存储。访问令牌、已登录设备的独立撤销令牌、加入设备的随机 claim 仅以哈希形式存在服务器内存。二维码包含配对凭据，请仅供目标设备扫描。界面不展示或复制链接，也不提供手动输入入口。
- 单文件 100 MiB，数据帧不超过 16 KiB，每块验证认证标签、序号及预期长度；可靠有序通道、最多 64 个未确认分块（不足 1 MiB）、发送缓冲水位控制。接收端校验并写入后才确认，显示进度、平均速度和预计剩余时间，完整保存或交付浏览器下载后才回执成功。
- 支持保存文件选择器的桌面浏览器逐块落盘；其他浏览器通过 Blob 下载，上限 32 MiB，避免在手机上聚合大文件。
- 配对有效期 15 分钟，包括已建立的连接；到期后两端关闭会话。最多 64 个信令房间，每账号最多两个；单份 SDP 密文上限 32 KiB。单个文件完成后保持配对，断开配对时清理信令。异常退出留下的信令到期清除；服务端重启或授权失效由已登录端的状态检查结束连接。
- 加入设备首次提交应答时绑定 128 位随机 claim，相同 claim 与相同密文可幂等重试，其他设备不能替换。未配对者不能撤销；已登录设备需登录、CSRF 和独立撤销令牌，加入设备需访问令牌和已绑定 claim。已登录设备配对后每 10 秒检查服务端授权状态；会话撤销会触发断开。
- 匿名权限仅用于这次两设备配对，不授予账号、画布或创建新配对的权限。匿名接口按 IP 内存限流并检查来源，自定义凭据头和 JSON 写入拒绝跨站访问。控制消息最多排队 32 条、每条 4 KiB，并限制每 10 秒不超过 100 条，拒绝未授权的数据通道。
- 连接信令使用退避重试；文件等待对方确认上限 120 秒；文件通道 30 秒无进展即停止，最终保存回执上限 60 秒。连接每 10 秒交换加密心跳，35 秒未收到控制消息结束连接。断网/后台限制造成的真实超时取决于浏览器调度。
- 篡改、乱序、截断、取消等失败会停止文件并中止未完成的文件选择器写入；Blob 只在完整校验后触发下载。不提供断点续传；文件通道失败可在仍有效的配对中重新发送，设备连接断开则需重新扫码。Blob 下载只能确认交给浏览器，不能确认用户最终落盘。
- 默认使用 Cloudflare STUN 发现直连路由；管理员可设置 `QUICK_TRANSFER_STUN_URLS` 为逗号分隔的 STUN 地址，空字符串表示只尝试本地候选。STUN 不传输文件，但会获知连接源 IP；直连双方也可能获知对方网络地址。没有 TURN 或服务器文件中转兜底，严格 NAT、防火墙、部分移动网络可能连接失败，可尝试同一 Wi-Fi 或换网。
- 从旧版临时目录中转升级不会自动删除旧目录；部署维护时应核实并清理操作系统临时目录下原有 `museboard-quick-v1-*` 目录。新版不会创建这些目录。
- 生产使用 HTTPS；本机可使用 localhost。

## 五子棋

- 点击面板外部区域可收起五子棋界面，保留对局进度和待处理邀请；再次打开即可继续。
- 15 × 15，无禁手，黑方先行，连续五子及以上获胜。满盘无胜者自动判和；旧版遗留的满盘未结束棋局会在升级时转为平局。
- 邀请当前共享组中有权访问当前画布的成员。每局创建时固定黑白双方，其他成员不能加入、代替或操作该局。同一对成员在同一画布最多有一份待处理邀请或一局未结束对局，但可以与其他成员同时进行独立棋局；不同画布也相互隔离。单人单画布最多 32 份有效邀请或未结束对局。
- 多场对局通过「对局」下拉菜单切换，使用现有工具栏的选择器样式。切换只改变显示的棋盘，不改变各局的轮次、棋子、对手、暂停或结束状态；新邀请、他人落子和后台刷新不会抢走当前选择。
- 邀请成员、邀请卡片、对局切换与棋盘双方信息显示成员头像和姓名；仅加载本站已有的账号头像，没有头像或加载失败时显示姓名首字。下拉菜单支持键盘选择，手机端限制在屏幕内。
- 邀请保留 10 分钟，开局前可接受、拒绝或取消；开局后不能取消或更换对手。未结束棋局持久保留，不因在线时长或关闭网页自动结束；已经结束的历史保留 24 小时。旧版没有画布关联的棋局，会在首次从双方有权访问的画布打开时绑定该画布，保留原进度。
- 任一方退出全部网页或登录会话失效后，由服务端连接状态将相关对局暂停；棋盘显示毛玻璃「已暂停」遮罩，该局不能落子，但在线方可认输结束它，也可与其他成员另开独立对局。双方重新在线后，离线暂停自动恢复。后台标签页、切换画布以及同账号仍有其他在线标签页不视为退出。突发断网在现有 WebSocket 心跳发现失联后暂停，本机连接中断则立即禁用棋盘。
- 对局中任一方可以点击「暂停对局」。主动暂停同样保存并锁定棋盘，但不会在重新上线后自动恢复；双方在线时，任一方可点击遮罩中的「继续对局」。暂停状态持久化，服务端重启后仍保留；权限撤销检查始终优先执行。
- 服务端校验双方账号、当前共享组、棋局参与者、轮次、坐标、空位和胜负；重复提交最近一步不会重复落子；数据库更新同时校验版本和手数，拒绝过时写入。棋盘长度、棋子值、手数与黑白棋数量不一致时阻止写入。离组后不能继续查看或操作旧对局；变更提示发送前也检查当前权限和有效会话。
- WebSocket 仅发送账号范围内的变更提示，客户端通过独立 API 拉取权威状态；面板打开时五秒兜底刷新，收起时三十秒，后台一分钟；失败退避，无重复轮询请求。棋盘只在打开面板后创建，复用 225 个按钮。同一次请求内复用成员在线状态，减少多对局的重复会话查询。
- 棋盘只有一个 Tab 入口；方向键逐格移动，Home/End 移动至行首/行尾，Ctrl+Home/End 移动至棋盘首尾，Enter 或空格落子。非落子回合仍可用键盘查看已有棋子。状态栏区分你的回合和等待对方，提交时显示等待提示，读屏会播报回合变化。
- 有待处理邀请时，五子棋图标显示红点，接受、拒绝、取消或过期后消失；不依赖浏览器通知权限。

棋盘支持落子预览、回合提示、已知手数编号、双方确认的悔棋和再战邀请。悔棋请求等待期间双方不能落子；仅对手可同意或拒绝，同意后撤回最新一手。再战会建立独立的新局，保留上一局结果。邀请通过模态弹框明确接受或拒绝。

## 浏览器通知

聊天与五子棋共用「桌面通知」开关和当前浏览器的推送订阅。在任一入口开启或关闭后，另一入口同步更新；只在主动开启时请求浏览器权限。聊天的消息提醒范围仍由聊天设置控制。

开启「桌面通知」后，关闭网页也可接收聊天和五子棋邀请。两者复用浏览器订阅与 `WEB_PUSH_*` 配置（见 `.env.example`，可运行 `npm run setup:push`），通知内容和点击后的目标页面分别处理。已有的聊天订阅直接适用于五子棋，旧的独立邀请偏好不再限制发送。

推送使用独立、限量、可重试队列，发送前重新检查邀请有效期、组成员关系、画布权限和订阅会话；通知不包含成员姓名或画布内容。点击邀请通知后重新验证权限，并打开对应画布和棋局。浏览器权限、操作系统设置或推送服务网络可能影响实际投递。

隐私锁触发时关闭面板；账号切换或退出时取消旧请求并清理面板状态。画布切换使用独立请求作用域，过期回调不能改变新画布的忙碌状态；落子和邀请发生变化时丢弃更早发出的列表响应，防止棋盘回退。原有画布编辑锁只阻止画布工具，不阻止快传和五子棋入口。
