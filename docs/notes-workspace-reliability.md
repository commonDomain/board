# 笔记模式核查与修复记录

核查日期：2026-10-03。本文对应本地实现与自动化验证，不代表生产部署或实体移动设备验收。

## 界面与编辑体验

- 统一字体、主题颜色、圆角和工具区样式，增加小屏触摸目标。
- 小屏提供笔记目录抽屉，支持新建和切换页面；窗口和侧栏尺寸变化时重新计算页面宽度。
- “所有笔记”跨笔记本展示；搜索补充云端内容结果和分页。
- 工具栏随文本选区更新加粗、字号等状态；撤销后保留编辑焦点，支持继续中文输入。
- 表格提供行列增删、合并拆分，链接支持打开与移除。
- 绘写提供实时笔迹预览；矩形选择明确标为“框选”。画布与笔记复制生成独立 ID，保留支持的文字样式，不支持的内容提供降级提示。

## 保存、隔离与异常处理

- 请求发起时固定账号、CSRF 和所属存储；切换账号中止旧请求并清理剪贴板、待放置内容、对话框与编辑状态。
- 本地存储从整库快照迁移为按笔记本写入，事务检查版本，防止旧窗口覆盖新数据。支持 Web Locks 的浏览器使用窗口锁，其余环境使用本地租约。
- 云端保存保持版本检查、编辑租约与操作幂等；冲突笔记不会阻塞独立副本保存。只读状态同步到正在编辑的文本和标题。
- 分清“仅在内存”“已保存到此设备”“已同步到云端”，配额失败不会误报保存成功；请求设超时和重试退避。
- 保存期间的新编辑不会被旧响应清除；永久删除等待写入完成，未保存或冲突时拒绝继续删除。
- 图片限制类型与大小，处理上传、解码和加载错误；切换页面后丢弃旧页面迟到的上传结果。
- 文档校验覆盖 ID、目录空条目、富文本结构与链接、尺寸、脑图深度及笔迹点数；限制绘制画布尺寸。
- 账号注销删除独立笔记、相关记录与资源引用，并清理对应本地缓存。资源物理清理由已有资源回收机制处理。

## 性能与容量

- 列表使用目录摘要，打开笔记本时加载正文；条件刷新无变化时不传整份正文。
- 云端后续保存发送变化页面及顺序，首次保存仍发送完整笔记本；本地按笔记本持久化。
- 素材与原稿查询使用索引记录和分页，避免每次解析所有画布正文。
- 大页面按可视区域挂载元素；打印时挂载完整内容。图片延迟加载，撤销历史设容量限制。
- 保存回执保留最近 1000 条；提供存储容量查看、回收站永久删除。

这些优化不等同于字符级协同编辑。当前冲突策略为编辑租约、版本检查和人工选择恢复或另存副本。

## 备份与恢复

- “视图”提供重试保存、另存副本、加载已保存版本、备份导入导出、游客笔记导入和容量查看。
- 导出 `.muse-notes.json` 包含图片数据；导入重新生成 ID，保留原笔记。加载已保存版本与永久删除需明确确认。
- 游客导入保留游客原副本，并按账号、源笔记和本地版本记录导入状态，避免重复导入同一版本。
- 本地旧整库记录在分本迁移时保留；旧画布笔记元数据在清理事务中归档到 `legacy_notebook_recovery`，可供管理恢复。此前已被旧版本删除且无备份的数据不能由本次修改恢复。
- 浏览器未能落盘时，内存草稿仍可能因强制退出而丢失；状态提示和离开提醒会明确告知，建议导出备份后处理设备空间问题。

## 2026-10-04 保存、同步与长文加固

- 区分离线缓存、保存拒绝、冲突与已同步；无效 JSON 或无效保存版本不作为成功处理。明确拒绝后修正内容生成新操作，网络结果未知时复用原操作保证幂等。
- 云端目录每 15 秒条件检查一次，恢复前台或联网时立即检查；版本未变不传目录。跨设备删除当前笔记时改为只读，保留副本恢复入口。正文无变化时服务端只查询版本，不读取正文。
- 异步打开和隐藏使用生命周期令牌；打开失败可点击状态重试。临时菜单操作释放非当前笔记的编辑锁，隐藏时先等待当前保存再释放锁。
- 刷新不替换正在输入或手势操作的页面；素材转换结果绑定选择和筛选令牌，防止迟到结果替换当前选择。
- 文字内容允许高于 20000 像素，图像和笔迹仍限制尺寸；观察正文实际高度以更新页面范围和虚拟化判断。撤销历史按快照缓存大小，避免反复序列化整个历史栈。
- 表格按钮根据当前选区能力启用，进入或离开表格更新工具区；链接对话框绑定原编辑器，标题输入保留原生撤销，没有历史时撤销不销毁编辑器。
- 新增拒绝后修正、超时后继续编辑、离线状态、跨设备目录、输入期间刷新等回归；浏览器验证 1000 段长文保存恢复和滚动、隐藏期间打开完成、非当前笔记菜单锁释放。真实设备和 Safari 仍需单独验收。

## 2026-10-04 双向定位与区域引用

- 画布素材副本新增“查看画布来源”，跳回来源画布并定位、选中元素；画布选中内容后点击“查看引用笔记”，可打开对应笔记并选中引用内容。查询仅返回当前账号的笔记。
- 画布框选内容后点击“引用选区到笔记”，向当前笔记插入区域预览，保留区域坐标、来源画布和元素 ID。预览使用现有 PNG 渲染流程，最长边限制为 1600 像素。
- 点击预览或“查看画布区域”返回原区域。打开预览时检查源内容，亦可点击“检查更新”；变化后点击“刷新预览”更新快照，不覆盖笔记其他内容。
- 区域是固定坐标范围，移入、移出、修改和删除元素会影响更新状态。来源删除或无权访问时保留最后一次预览并显示状态，跳转和刷新重新检查访问权限。
- 区域图沿用图片上传、资源引用、备份与存储流程，支持游客本地保存和账号云端保存。来源关系沿用笔记保存，不修改画布原始内容。
- 验证覆盖来源匹配、区域变更、元数据校验、跨账号接口隔离，以及浏览器中的生成预览、双向定位、更新提示与刷新流程。

## 2026-10-04 笔记界面与移动端整理

- 工具栏默认保留常用编辑入口，其他工具通过“更多工具”展开；桌面编辑文字时显示完整格式控制。原有功能继续可用。
- 使用明确的画布/笔记模式切换；手机显示“目录”和“素材”文字入口。目录采用笔记本、分区、页面逐级导航，带返回、路径和关闭操作。
- 素材筛选折叠显示，图片和脑图提供内容预览，来源以标签显示；选中状态和插入按钮固定在面板底部，窄屏插入后回到正文。
- 空白页提供写文字、插入图片、从画布添加入口；弱化页面元信息，区分笔记本、分区与页面的选中层级。
- 区域引用采用预览、来源、更新状态与操作组成的卡片。新插入图片及引用在窄屏适配正文宽度；修正文字默认右侧留白引起的横向溢出。

## 2026-10-04 写作、搜索与画布往返整理

- 保留自由页面和现有笔记格式。桌面工具栏进入文字编辑时不再自动展开全部工具；备份、导入、存储容量和触控设置移到工作区菜单，保存状态可直接打开恢复操作。
- 手机搜索按需展开，已打开笔记使用当前页与切换列表。搜索结果展示来源路径、命中摘要，并直接定位对应内容；保留查询词，搜索刷新不打开目录或抢走输入焦点。云端搜索摘要从匹配位置附近截取。
- 标签支持关闭其他、关闭全部但保留当前；关闭当前页后回到最近使用页。单标签不显示无效关闭按钮。
- 文字输入时隐藏移动、缩放和对象操作手柄；删除收进内容菜单。插入素材后滚动并强调新内容，待放置状态有直接可见的取消入口。
- 画布的笔记操作收进同一个菜单。引用选区先确认目标页，也可在当前分区新建页面。查看来源后提供一次性返回入口，恢复原笔记阅读位置与选区。
- 区域引用刷新采用临时隔离渲染文档，复用画布渲染与 PNG 导出代码，不启动账号、画布会话、WebSocket 或持久化生命周期，不切换主界面的活动画布。读取来源前后校验权限及内容版本；失败保留旧预览，刷新不重建当前文字编辑器。
- 新增只读数据接口 POST /api/notebooks/region-preview，沿用 region-status 的账号、CSRF、来源权限与区域参数校验，仅返回区域内元素及渲染所需图层、背景信息。无存储格式迁移。
- 验证：构建及静态检查、38 项单元/服务端测试、完整 Chrome 浏览器回归。新增浏览器用例覆盖长页搜索定位与焦点、标签访问顺序、编辑防误触、跨画布刷新时保留编辑器/滚动/选区/画布历史和视角、来源失败、返回笔记、引用目标取消/确认/新建及实际插入。服务端补充预览接口跨账号隔离和参数校验。
- 实体移动设备软键盘和 Safari 仍需真机验收。
