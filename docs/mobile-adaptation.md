# 移动端适配与验收

## 交互约定

优先 iPad Safari、安卓平板 Chrome；手机保留原有功能入口。布局按可用宽度切换，1100px 以下收起笔记双侧目录并使用画布底部工具栏；760px 以下进一步压缩布局。粗指针设备即使更宽也采用触控热区，支持外接鼠标与键盘。

双指移动与缩放基于起始内容锚点，画布旋转默认关闭。`wb:touch-preferences` 仅保存本机的 `penOnly`、`rotate` 布尔偏好；不修改文档、服务端协议或数据库。笔记沿用独立存储，与画布通过复制交换内容。

笔记的文字输入、浏览与元素变换分别通过轻点、滑动和选中手柄触发；绘写时默认允许手指，开启仅笔模式后手指浏览。第二指加入会撤销未完成手势。笔记橡皮在手势完成时提交，以便取消操作。已有元素不会因设备宽度或键盘变化自动重排。

| 功能组 | 本次处理 | 验证方式 |
| --- | --- | --- |

| 画笔及放置工具 | 手指绘画、仅笔设置、轻点确认文字等放置、滑动不创建 | Chrome 多触点事件 |

| 笔记目录 | 平板抽屉、操作按钮常显、排序手柄及上下移动菜单 | 六种视口布局、触控排序回归 |
| 笔记输入与格式 | 保留富文本编辑器、中文输入、完成编辑、可滚动格式工具栏 | 既有富文本回归及触控输入回归 |
| 电子表格 | 单指滚动、显式区域选择、双击输入、取消不提交尺寸变更 | Chrome 双轴滚动、区域选择及中文输入 |

| 导入导出、保存、复制 | 保留现有文件与数据接口；新增放置取消入口 | 既有笔记复制、备份往返、刷新恢复回归；系统文件操作待真机验证 |
| 键盘与视口 | 跟随 VisualViewport 高度与偏移、输入光标避让、弹窗限高、方向变化取消未完成手势 | 源码检查；真实软键盘及分屏切换待验 |

## 构建与检查

执行 `npm run build`、`npm run check`，检查构建、语法和模块依赖。

项目已移除触控测试脚本与测试截图。交互需在目标设备上检查：轻点与滑动区分、双指平移/缩放、旋转开关、绘画中第二指接管、取消笔画、仅笔偏好、笔记移动/调整宽度/排序、中文输入、表格滚动/选择/编辑，以及缩放控件与底部工具栏位置。

## 真机待验

- iPad Safari：Apple Pencil 压感及笔掌共存、中文候选栏、系统文字选择、浮动键盘、横竖屏与分屏。
- 安卓平板 Chrome：不同系统输入法、手写笔事件、键盘调整视口、系统返回键及长按菜单。
- 手机 Safari/Chrome：工具栏横滑、键盘上方完成按钮、剪贴板、相册/文件选择、下载和打印。
- 所有目标设备：复杂脑图、连接线与画框拖动、图层和排版菜单、登录后的权限/共享、离线恢复以及大文档手势性能。

真机项目未执行前，不将自动化结果描述为 Safari、Apple Pencil 或全部移动设备兼容认证。

## 设备识别与菜单定位

进入网页时结合 UA、平台、触摸点数和指针能力识别设备，不以窗口宽度判定移动端。兼容 iPad 桌面网站 UA；Windows 触屏电脑保留桌面界面。触控设置、触控操作条、笔记触控快捷操作和表格触控选择仅在移动端显示，窄屏桌面仍保留必要的导航入口。

画布工具、画布切换、右键及笔记原创内容菜单根据入口和可见视口选择展开方向，避让工具栏；手机使用视口内宽面板。菜单随窗口尺寸、可见视口和内容尺寸变化重新定位。
