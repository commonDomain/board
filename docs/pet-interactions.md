# 工具栏宠物互动

桌面画板的「宠物」菜单提供显示、关闭、喂食、扔球、工作反馈。只有一个喂食按钮，每次投喂等概率随机选择「叼回工具栏附近再吃」或「就地吃完，开心翻滚后走回工具栏」，一次互动中不会重新抽选。点击喂食或扔球后，鼠标在画布内变成对应道具；点击画布任意可绘制区域选定投掷位置。宠物连续跑过去，完成互动后返回左侧工具栏。Esc、右键或再次点击同一个互动按钮可以取消选点；画布控件仍可操作。右键点击宠物也可进入投掷模式或暂时隐藏。关闭宠物及工作反馈偏好保存在当前浏览器。

## 动作和互动

- 静态姿势统一以脚底居中对齐，动作交叉淡入时不会随图片边界漂移。
- 睡醒依次经过趴卧、坐起、站立；入睡经过坐下、趴卧。移动沿用距离驱动的步频、加减速和落脚，登场采用平滑速度曲线。
- 跑步采用六帧贴地小跑，复用现有四足交替资源，避免慢速移动配上腾空疾驰。小跑速度为 116 CSS 像素/秒、每 64 像素一个周期，慢步为 76 像素/秒、每 48 像素一个周期，叼回为 88 像素/秒。加减速时步频随实际位移变化。身体轻微起伏与落脚相位同步。朝向按路径实际切线选择，纵向使用已有前视/后视双帧，斜向边界使用滞回避免反复转向。
- 喂食：零食立即在投掷位置轻轻落下。宠物起身后连续跑过去，随机选择叼回工具栏附近再分三口吃完，或在原地低头、咀嚼舔嘴、开心回应、短距离翻滚后慢步回到工具栏。吃东西使用专属嘴部动作帧，每口包含咬下、两次小幅咀嚼、闭嘴停顿，三口约 3.3 秒，食物随咬下减少，最后舔嘴并抬头。翻滚使用蜷身、肩部着地、翻过背部、收腿落稳的竖向翻滚资源，每次完整翻滚 1.25 秒，最多两次；蜷身和落地留足时间，滚过背部稍快，落稳暂停 220 毫秒，再起身慢步返回，不再用 CSS 旋转整张趴卧图片。零食的位置保持固定。
- 扔球：短暂期待后，追赶与抛球同时进行；球沿抛物线飞行，经过两次逐渐减小的弹跳和滚动停下。宠物低头靠近、轻轻拾起、以稍慢的小跑叼回工具栏、低头放下、开心回应。
- 拾球只经过站立低头、咬住、抬头和转身，不插入坐下、趴卧及重新站起。携带道具跟随专属动作帧的嘴部位置。少量爱心增加反馈，不使用循环粒子系统。
- 主动互动可中断日常动作；同一时间只执行一次主动互动。工作反馈最多保留一个待播放事件，15 秒后失效，不积压动画。

## 工作反馈

- 规划任务从未完成切换为完成，并成功保存到浏览器或服务器后，短暂庆祝。远程刷新、失败的提交和重复的完成状态不触发。
- 主动保存画布：服务器确认当前修改已持久化，或游客画布确认已保存在浏览器后回应；自动保存不触发。
- PNG 图片生成并交给下载／预览流程后回应，不推断用户设备已完成文件下载。
- 普通工作反馈共享 30 秒冷却，最近 64 个事件标识去重。关闭反馈可立即结束正在播放的庆祝。

## 性能和生命周期

宠物关闭或尚未登场时不请求姿势资源。图片解码完成后再登场，单个姿势失败时复用已成功解码的姿势；全部失败时可点击显示宠物重试。专属动作统一打包到 `public/pet/corgi-motion-atlas.webp`，两个显示层共用同一图集 URL，只在动作帧或朝向变化时更新图集位置。图集失败时退回旧姿势，翻滚返回退化为步行返回。道具由 CSS 绘制，鼠标图标使用两个很小的 SVG。追赶、抛球、咀嚼、翻滚共用同一个 requestAnimationFrame，不创建并行动画循环；选点使用原生鼠标图标，无鼠标跟踪渲染循环。停留阶段只用一次性计时器及 CSS 动画。工具栏和按钮几何信息只在布局变化时更新，不在运动帧里读取布局。

每个动作序列使用版本标识和可取消等待。隐藏、切换到笔记、后台、页面挂起、减少动画偏好变化或活动区域变化时，中止旧序列、清理道具、选点状态、取消帧和等待，不在恢复时执行旧回调。更换画布后取消未完成的选点。投掷手势在捕获阶段被消费，不触发绘图、选择或编辑器草稿提交，也不把宠物道具加入画布文档和同步队列。页面退出／返回支持浏览器往返缓存；`destroy()` 清理事件、观察器和节点。

系统开启「减少动画」后，保留喂食、捡球和可读文字反馈，移动改为直接定位，关闭跳动、抛球和循环姿势动画。手机和触屏设备沿用现有隐藏规则。
