# 画布群聊

左侧工具栏创作栏最下方的「笔记」「聊天」分别打开笔记操作和当前画布的成员群聊。首次使用点击「添加画布群聊」；数据库以画布 ID 为主键，重复添加始终打开同一个群聊。群聊独立保存，不占用画布对象，也不参与画布撤销历史。

- 只允许登录后有权访问该画布的成员使用。私有画布只有所有者可见；取消共享后，读写消息与查看聊天图片的权限随之撤销。
- 新成员仅能查看加入前最近 30 条及加入后的消息。边界按共享成员加入时刻持久保存，离开后重新加入会重新计算；画布所有者保留完整历史。分页、增量同步、搜索和结果数量、上下文跳转、引用预览、引用发送及图片访问均核验同一边界，不能通过其他入口读取更早内容。消息只保存一份，不复制给每位成员。
- 支持文字、200 个常用 emoji、PNG/JPEG/WebP 图片（界面限制 8 MB），图片可以选择、粘贴或拖入。原图保持原始字节，列表使用缩略图，查看器先加载预览并提供原图与缩放入口。点击表情框外区域或按 Escape 关闭表情框。
- Enter 发送，Shift + Enter 换行；输入法选字期间的 Enter 不发送消息。发送失败保留内容与回执 ID，重复提交或重试不会重复发送或恢复已撤回的内容。图片上传显示进度、可取消，独立超时 180 秒（全局请求包装器也遵循此时限）；上传期间可以继续输入，新输入不会被当前发送清空。点击窗口外部、关闭按钮或 Escape 隐藏面板时，正在上传的消息继续上传并发送；重新打开显示同一次发送状态，后台完成不会抢走焦点。切换画布、笔记模式或账号仍结束原上下文请求。关闭面板或切换画布保留隔离的内存草稿（最多 4 份、1 小时）；退出账号与权限撤销清空草稿和图片查看器。
- 消息右键菜单支持引用、撤回、从我的记录隐藏（键盘 Shift + F10 也能打开）。引用显示在正文下方，以灰色摘要、昵称和细竖线区分；自己的引用右对齐。图片、视频引用同时显示缩略图，输入区的待发送引用也有预览。引用区域支持右键或 Shift + F10 选择「定位到原文位置」；点击图片或视频缩略图可打开图片查看器或视频播放器。读取缩略图、打开媒体和定位均遵循成员历史边界，原消息撤回、个人隐藏或视频清理后同步更新引用。撤回没有时间限制，只能操作自己发送且仍可访问的消息，后端再次核验发送者和画布权限。
- 删除仅从当前账号的记录中隐藏，其他成员的记录保留；所有设备通过消息版本同步删除结果。
- 搜索覆盖当前成员有权查看的聊天历史，支持 Unicode 大小写和 emoji，显示结果数量与高亮；搜索框聚焦无紫色外框。消息菜单可以跳转上下文。历史每批 80 条，最多渲染 240 条，可切换更早/较新窗口，显示日期和发送时间。成员下拉在聊天窗口内部定位，长名称省略显示，点击其他区域关闭。
- 聊天消息总条数不设上限，发送新消息不会自动清理旧记录。历史仍每批加载 80 条、最多渲染 240 条，按需浏览更早或较新的消息；旧消息的文字、引用、提及、回应及附件引用持续保留，撤回、个人隐藏和删除画布沿用原有规则。
- 未读数仅统计其他成员的非撤回、非隐藏消息。聊天关闭时也进行补偿查询，健康连接约 30 秒，断线逐步退避并加入抖动；工具栏显示数字红点，新增未读时显示 3 秒「您有 N 条未读消息」气泡。切换画布、账号时清理前一画布的提醒。
- 消息发送、撤回、清理、删除和已读位置更新通过现有 WebSocket 推送变化通知，窗口直接刷新消息、阅读人数和未读红点，无需重新打开聊天。通知仅发给会话有效且仍有画布访问权限的成员，删除通知仅发给操作账号；接口重新检查权限。连接恢复和页面重新可见时自动补齐，定时查询保留为断线补偿。请求期间收到的新通知会继续排队刷新。
- 每位成员的已读位置保存在数据库中。仅在页面可见、具有焦点、消息进入可视区域时推进累计已读位置（不表示每条旧历史都实际展示过）；搜索不会标记已读。消息左侧无人阅读时显示小空心圆，有人阅读后用蓝色小圆圈显示具体阅读人数（不计发送者）；点击圆圈打开人员浮层，再次点击同一圆圈收起，悬停不展开。切换“已读／未读”页签查看人数、头像和姓名，成员及阅读位置更新时同步刷新。支持键盘打开、左右箭头切换和 Esc 关闭，点击外部或关闭聊天时收起。
- 画布元素右键菜单的「加入聊天引用」打开群聊并添加待发送卡片，支持仅发送引用或附加文字、图片。画框不支持引用；点击已发送卡片定位到当前元素位置，已删除元素给出提示。后端核验元素属于当前画布。
- 聊天窗口固定位置与大小，输入框也禁止拖拽缩放。

### 聊天图片查看器

普通消息和引用图片使用同一查看器。图片最长边不超过 1600 像素时直接显示原图；更大的图片先读取 1600 像素预览，点击「原图」后读取原始文件。预览加载失败时回退原图；原图加载失败提供重试。列表和引用摘要仍使用最多 320 像素的缩略图。

查看窗口随图片尺寸自适应，并限制在可视范围内；图片按比例居中，剩余区域填白。窗口外框为细灰线、小圆角和柔和阴影。「原图」紧邻缩小按钮左侧：预览状态显示按钮，已加载原图时显示灰色文字。按钮或滚轮缩放只改变框内图片，窗口尺寸保持固定；在图片区域按住左键拖动可查看放大后的细节。关闭时释放图片资源与窗口事件监听，切换图片或视频时关闭前一个查看器，迟到的引用媒体请求不能覆盖后续选择。
- 文字和表情消息使用气泡；图片、视频及画布引用直接展示。附件附带文字时，仅文字部分显示气泡，引用预览和视频删除状态使用独立信息样式。「筛选与提醒」使用带边框的按钮样式。
- 点击发送后，文字、表情、图片及引用立即以本地消息显示在聊天记录中，输入框腾空后可继续输入。去掉等待确认、上传处理等发送提示文字和独立待发送条；文字/表情左侧显示旋转圆环，图片左侧按上传进度闭合小圆环（上传完成到 80%、图片处理完成到 90%，收到消息发送响应后结束）。发送完成恢复原有未读小空心圈及已读人数标识。失败或取消保留原消息，以红色图标表示，点击该图标使用同一回执 ID 和原始内容重试；编辑新草稿不改变失败消息。服务端消息按同一 ID 替换本地消息，避免重复显示。失败消息随原账号/画布的隔离内存草稿保留，重新打开会重建本地图片预览；退出账号或权限撤销清除。
- 成员头像和在线状态沿用账号资料；当前用户及持有有效在线 WebSocket 会话的成员显示在线。聊天面板通过 WebSocket 通知合并同步变化，辅以低频轮询，切换画布、账号或笔记模式时关闭并清理旧记录。
- 图片进入资产引用、来源记录和清理机制。撤回删除业务引用并在不被其他功能引用时撤销发送者上传授权；文件按孤立宽限和历史备份保留策略回收。删除画布时群聊和图片引用一并清理。
- 聊天支持 MP4、MOV、WebM、M4V 视频，默认单文件 512 MB，以 4 MB 分块通过现有加密接口上传。服务端检查实际容器、画面、时长（最多 4 小时）和分辨率（最多 8K），生成缩略图及最高 1280×720、30 fps 的 H.264/AAC 预览；并发转码限制为一个任务、两条编码线程，断开或取消会终止转码并清理临时文件。原视频保留原始字节及 SHA-256 校验值。
- 每块画布默认原视频总上限为 3 GB，缩略图和压缩预览不计入这个限额；上传中及尚未发送的原视频预占空间，避免并发超限。仅在发送视频时服务端判定空间不足，才打开视频空间管理弹窗；打开聊天或同步空间用量不触发弹窗。上限统一读取服务端 `.env` 的 `CHAT_VIDEO_LIMIT_BYTES`，修改配置后重启生效，用户界面和 API 均不能修改；旧数据库中曾保存的画布上限不再采用。单文件上限由 `CHAT_VIDEO_MAX_BYTES` 配置。
- 聊天记录使用带播放图标和时长的静态视频缩略图，点击后弹窗播放压缩预览。弹窗按原视频尺寸、比例和可用屏幕空间展示，点击「查看原视频」切换原画质；MOV/M4V 中浏览器不支持的编码可保存原文件在本地播放器查看。
- 视频空间管理弹窗展示所有当前成员有权查看的视频缩略图，可点击播放、多选（每批最多 40 个），每次先渲染 60 个列表卡片以控制 DOM 和请求量。只能清理自己上传的视频，画布所有者可清理所有有权查看的视频；新成员历史边界和从个人记录隐藏的规则同样应用于列表、缩略图、播放、下载和清理接口。
- 「保存并删除云端数据」只处理勾选的视频。支持 File System Access API 的浏览器先选择本地目录，逐个流式写入原文件，核对完整字节数并成功关闭文件后删除对应云端文件；失败或取消保留未成功处理的视频。其他浏览器使用原生下载，不将整个视频读入内存；无法证明文件落盘时，需用户确认浏览器已保存全部文件。服务端还要求同账号、同画布、同视频的完整下载凭据，HEAD、Range 和未完成下载不能授权删除。清理会同步移除原视频、预览和缩略图，保留文字「该视频因达到此画布视频文件总大小限制已被用户选择删除」及灰色撕裂视频图标，同时更新引用和其他设备的记录；重复请求不会误删其他视频。
- 播放和下载支持 HTTP Range 和响应流背压。缩略图、预览生成一次后在服务端复用，浏览器使用私有缓存与 ETag，复用前重新验证成员权限、历史边界和文件状态；原视频下载使用 `no-store`。正在上传或未发送的视频一小时后回收，撤回、画布删除和启动维护均清理失效文件。
- 新自动备份和手动备份仅保留聊天文字、表情及必要的历史元数据，不备份聊天图片、原视频、预览、缩略图或媒体引用。纯媒体消息不进入备份；带文字的媒体消息仅保留文字。处理只修改备份数据库副本，线上聊天和文件不变；同一图片如还用于画布、笔记或头像，则按对应功能的依赖备份。

笔记模式顶部新增个人资料头像入口，打开现有账号资料弹窗；保存状态附带最近成功保存时间。原「笔记操作」入口现为创作栏最下方的「笔记」。

发送区域使用一个「添加图片或视频」附件按钮选择两种媒体，也支持从剪贴板粘贴图片或视频文件，识别剪贴板文件列表和文件项；缺少视频扩展名时按常见视频 MIME 补全名称。先展示待发送附件，点击发送后上传，沿用格式、单文件大小和画布原视频总量限制。普通文字粘贴保持原有行为，每条消息最多一个附件。

## 提及、回应与重要信息

- 输入 `@` 或点击输入区的 `@` 按钮选择当前画布成员。支持输入姓名筛选、上下箭头选择、Enter / Tab 确认和 Esc 关闭；输入法选字不会发送。提及以成员 ID 与文字位置保存，同名不会串人，编辑破坏原文字后自动取消该提及。服务端核验成员、文字位置与姓名。每条消息最多 20 次提及；发送回执包含提及内容，已发送消息在成员改名后仍能按同一回执重试。
- 被提及的消息显示“提及你”，「提及我」汇总可查看的历史，并显示未读提及数量。「筛选与提醒」内可设置全部消息、仅提及我、关闭提醒；按账号和画布保存在服务端，实时同步同账号设备。关闭提醒只取消气泡，未读数字保留。提醒仅在本应用打开时工作。
- 点击消息下方的表情计数按钮、消息旁的笑脸按钮或菜单中的“表情回应”，可打开弹窗查看回应成员。在弹窗内添加或取消自己的回应，提供「收到、+1、好的、搞定、是的、明白、👍、👌、666、🌹、🎉」11 种选择；文字表情使用彩色标签，旧表情回应保留查看及取消能力。同一成员、同一表情只能回应一次，请求显式设置状态，重复请求不会反复切换。
- 选择表情后立即收起弹窗，在聊天记录中显示或取消自己的回应，后台提交时标记“正在保存…”。同一消息的同一表情在确认前禁止重复提交，其他表情仍可使用。失败只回退该次本地回应，保留其他成员的最新变化，并在消息下方提供重试入口；切换账号、画布或消息失效时取消旧上下文操作。
- 服务端直接返回该消息的回应及版本，客户端据此确认，不再为自己的成功提交额外刷新整个列表。版本保护避免迟到响应或旧查询覆盖较新的回应；兼容仅返回成功标记的旧服务端，等待同步确认时保持本地显示。回应更新仅替换表情区域，复用消息文字、图片和视频缩略图。
- 回应弹窗随成员与回应变化更新；原消息撤回、隐藏或不再匹配当前筛选时收起。已离组的回应成员仍显示现有账号姓名。
- 群公告独立于聊天消息保存，所有当前画布成员可查看当前公告；画布所有者在聊天顶部点击「添加群公告」，输入内容后点击「保存公告」。已有公告时入口显示「编辑群公告」；只有画布所有者可以编辑，最多 2000 字。多窗口编辑进行版本校验，冲突时保留当前输入并提供载入最新公告入口。公告与聊天文字均按纯文字呈现。
- 回应、公告及提及通过既有 WebSocket 变化通知同步；撤回清理该消息的提及和回应，画布删除通过外键级联清理。个人隐藏仅改变该账号的可见性。

## 将消息保存为成果

- 消息菜单的「生成便签」允许调整文字，在当前可编辑图层生成便签，沿用画布保存、撤销及协作队列。便签菜单的「打开来源聊天」可回到原消息。
- 「加入笔记」可选择已有笔记，或新建私有的「聊天摘录」笔记本。文字与图片复制为独立内容，保留来源入口；视频保留来源入口。目标笔记共享范围在选择器中显示，插入遵循原有页面编辑锁、保存版本与本地草稿机制。云端保存未确认时保留副本，并通过同一副本重试保存，避免重复插入。
- 启用规划后，「创建任务」可选择当前画布已有规划或新建规划，编辑标题与消息正文。任务保存独立来源信息，详情可打开来源聊天；沿用规划操作回执、冲突与草稿机制。新建规划时添加原有规划组件。
- 复制前重新核验原消息、成员历史范围、个人隐藏及撤回状态；图片副本通过已有资产授权与目标引用保存。副本保存成功后独立于原消息，原消息撤回不会删除已经明确复制的成果。来源定位始终重新核验访问权限，原消息不可用时保留当前聊天草稿。
- 提交时固定目标笔记或规划，并在异步读取后再次核验账号、工作区与弹窗状态；取消操作或切换账号后不再插入内容。已有笔记只追加元素。规划与任务请求丢失回执时重放原操作，不重复创建；已经提交的目标与任务正文在重试期间固定。
- 手机沿用现有画布和笔记只读模式，可完整使用聊天、提及、回应、公告、筛选及附件查看；生成便签、笔记和任务在平板及电脑编辑模式使用。

## 筛选与附件

- 「消息」「提及我」「附件」共用关键词搜索与分页；「筛选与提醒」位于标题右侧，打开浮层可组合成员、附件类型和日期范围，或设置个人提醒。日期按浏览器本地日期边界筛选，结束日期包含整天。已有可查看历史中的离组发送者也可筛选。
- 「附件」汇总图片与仍可播放的视频，支持原有预览、原图、视频播放和上下文跳转；视频空间管理弹窗在发送视频空间不足时出现。已撤回、个人隐藏或超出成员历史边界的消息不进入结果。
- 搜索、筛选和附件浏览不推进已读位置。每批最多 80 条，聊天仍最多渲染 240 条；提及与回应按当前批次 ID 批量查询，避免逐消息读取数据库。
- 筛选中的实时变化携带匹配状态，在当前列表中更新或移除消息，保留历史窗口和滚动位置；无需每次变化重新加载整页搜索结果。提醒设置和公告保存也不重置筛选历史。
- 数据库采用增量建表，不改写现有聊天消息、画布、笔记及任务。
