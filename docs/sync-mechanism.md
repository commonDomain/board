# 画布与 XMind 同步机制

## 数据路径

1. 编辑操作先更新客户端模型，再进入 `WhiteboardSyncQueue`。队列按顺序发送操作，并用稳定的 `opId` 处理断线重发。
2. `WhiteboardStorage` 把未确认操作写入 IndexedDB 的 outbox，并以 localStorage 作为小容量兜底；画布快照另存于 snapshots。重新打开画布时先恢复本地数据，再连接 WebSocket。
3. 服务端在画布队列中校验操作、版本和权限，使用数据库事务提交状态与操作回执，随后向所有连接广播规范化操作。客户端收到确认后删除 outbox 中对应操作；版本冲突则拉取权威快照并重放未确认操作。
4. 保存请求在操作队列清空后提交。页面短时离线时操作留在本机；服务端写入成功、客户端未收到确认时，重连后仍用原 `opId` 重发，服务端按回执去重。

## 按元素编辑租约

服务端按连接和元素维护 3.5 秒租约。进入便签、文字、表格、脑图文字/备注、连接线标签、拖动/缩放/旋转和全屏工作表编辑前，客户端先取得服务端确认。多选和画框操作一次申请全部目标，任一目标被占用时不部分占锁；不同元素可以同时编辑，同账号的不同标签页也互斥。

普通点击选中、悬停不申请租约；普通移动跨过拖动阈值才申请，多选包含远端占用成员时整次拒绝。请求按服务端画布队列顺序处理，确认最新版本后才打开编辑器。同一连接的重复申请合并，已确认的有效租约可复用。锁定元素的外层保留鼠标命中及禁止图标，内部控件禁用；捕获阶段拦截写操作，避免点击穿透到画布或下层元素。

编辑器、弹窗及指针手势仍在使用时约每 900 毫秒续租。结束操作且最后一笔提交已确认后主动释放；断线、切换画布或超时释放对应连接持有的租约。前台编辑中停顿不会提前解锁。失败草稿不无限续租，仍保留本地操作。解锁消息携带提交版本，接收端仅等待对应元素所需的版本，不让其他元素进入整画布只读。清空画布和调整整套图层属于文档操作，需要短暂排他；普通内容编辑不使用整画布锁。

正常结束使用 120 毫秒释放缓冲，短时间重新进入同一元素会取消释放；最后一笔确认到达后立即安排释放，不额外等待下一轮心跳。多元素心跳、释放及服务端广播按批次发送，每个画布共用一个租约到期定时器。续租仅更新到期时间，锁状态变化时才刷新交互界面。编辑活动与鼠标位置使用独立限流额度，释放请求不被抢锁限流丢弃。批量锁消息与操作确认一同在分块快照完成后按顺序处理。工作区协同协议为 4，旧页面需要刷新。

服务端对规范化操作实际改变的全部实体再次校验，包括绑定连接线、画框子元素、空分组及层级迁移目标，防止派生更新绕开锁。单元格续租同时检查工作表元素租约，失效的单元格锁不能跨过另一位成员的元素锁。

页面隐藏时先收集并保存输入，空闲编辑活动经过原有缓冲释放；最终输入仍未确认时继续必要续租，确认后再释放。最后一个活动释放后取消心跳定时器；后台才收到的申请确认不能重新打开编辑器。单人画布继续使用相同租约、版本及提交校验规则。

后台只延后可以从当前模型重建的画布绘制、组织树及逐元素锁样式刷新，模型、索引、提交回执、草稿和连接恢复继续处理。前台、resume 或 pageshow 恢复时合并补绘；补绘按画布和会话隔离，切换时清除，显式导出可即时绘制。XMind 远端检查在后台取消定时器，返回时保留强制检查意图，已有同步写入仍按原规则完成。

## 元素版本与草稿恢复

所有 15 类画布元素、画框及分组保存服务端生成的 mutationVersion。操作入队时保存 expectedMutations；服务端在提交前比较对应实体版本，拒绝过期的整对象、几何和级联操作。已删除的实体与版本 0 的实体不同，旧草稿不能通过刷新画布版本将已删除对象复活。旧数据默认版本为 0；缺少校验信息的旧版未确认操作先按原 opId 查询回执，未提交过的则保留为待核对草稿，不直接覆盖当前对象。

新创建或删除后按原 ID 恢复的实体，从当前画布 revision + 1 开始使用 mutationVersion；现有实体每次实际改变再递增。因此同一 ID 的新实例不会复用先前实例的版本号，删除前的旧草稿在恢复后仍无法通过校验。

鼠标位置属于临时状态：40ms 严格限频并保留末位置，按连接区分光标，账号用于名称和人数。接收绘制按动画帧合并，隐藏页面或离开画布时发送移除，断线清除对应连接，30 秒无更新兜底清理。积压时可以丢弃位置消息，文档操作、锁和回执继续可靠处理。

收到本窗口操作的确认后，只重设后续未发送操作的版本依赖，并生成新操作 ID；尝试发送过的 ID 和内容保持不变，保证回执去重。不同元素竞争全局画布版本时可重新同步并重试，仍持有租约的编辑器保留 DOM、焦点、光标及输入。其他标签页即使使用同一账号，其未知操作也按远端操作处理撤销历史。服务端版本号不属于可撤销的内容，撤销和重做沿用当前版本依赖。

“恢复到原元素”使用当前服务端版本恢复最后的本地草稿，保留原 ID，内容恢复保留原位置及层级；明确的几何操作恢复其本地几何。恢复支持所有完整元素、几何、工作表和画框/分组操作，混合批次只替换相应部分，去掉过期的父批次校验并保留其他操作。恢复后的队列先可靠写入本机，失败时保留原队列和冲突备份；成功后才继续网络提交。

“同步问题”和冲突草稿面板中的“丢弃本地草稿，使用云端版本”在联网确认后，仅清理当前账号、当前画布在此浏览器中的 outbox、写入日志、冲突备份、工作表草稿和缓存快照。清理前暂停提交并等待已有本地写入结束，清理后重建当前画布运行状态并重新连接，强制读取完整云端快照，清空本地撤销记录。其他画布、其他账号和云端内容均不删除；离线、提交尚未确认或画布已切换时不执行清理。

## XMind 双向同步

只有连接的脑图内容与关系会同步到 XMind；其他画布元素通过画布服务端与 WebSocket 在成员间同步。画布脑图修改先作为普通画布操作提交，再自动调用 XMind 增量同步。服务端先检查远端哈希，应用结构化补丁，回读验证，最后推进同步基线。XMind 写入期间出现新的画布修改时，新修改留在待处理状态，由下一轮增量继续处理。

页面可见且连接有效时定期检查 XMind 远端变化，返回页面时强制检查。只有远端修改时自动载入，同时保留本地专属字段；两端同时改动时停止自动覆盖，并保留人工冲突处理入口。XMind 授权失效、远端拒绝或回读不一致时，画布内容仍留在本地和本站服务端，不会被静默丢弃。

## 故障恢复

- 登录画布的草稿按账号和画布隔离。IndexedDB v6 使用独立 outboxJournal，在同一读写事务内合并多标签页记录；localStorage 兜底按标签页写入。已确认、被合并的操作以删除标记保留，防止旧标签页或旧版 outbox 将它们复活。旧 outbox 只迁移读取，不覆盖新日志。
- 草稿读取失败或格式损坏时禁止编辑、禁止覆盖原存储，并自动重试；恢复完毕才允许加入同步。草稿写入失败时暂停编辑，每 5 秒重试；存储恢复后自动解锁。写入结果按画布、账号代次和编辑序号检查，旧写入完成不能把新输入误标为已保存。页面离开时仍有未落盘修改会触发浏览器离开提示。
- 登录/共享权限失效、数据版本不兼容，以及无法隔离的持久同步错误暂停编辑。明确识别的失败图片保留并隔离，不锁住能独立提交的便签、文字、背景。已接收的离线输入在本地保留，恢复连接后补同步；需要确认租约的共享编辑器在连接未确认时暂停接收新输入。
- 从服务器接收快照或提交前先收集尚未入队的文字输入，再重放草稿。连续的未发送便签/文字快照可合并，但每次替换使用新操作 ID；发送过的 ID 和内容不再变更。收到自己的提交确认后，只调整后续未发送操作所依赖的内容版本，真实的其他版本冲突仍由服务端拒绝；样式修改不能降低内容版本号。

- 本地草稿恢复与网络提交分开：队列中的错误仅暂停提交，不截断后续背景、文字等可重放草稿。离线启动、服务器快照及其他成员的提交之后均重新应用待提交修改；本地显示恢复不代表云端已保存。目标图层锁定时仍保留队列，且不覆盖锁定内容。
- 本地存储必须明确返回成功才算保存；存储接口缺失也视为失败，不能据此放行画布切换或标记缓存已保存。
- 服务端明确指出图片权限失败后，队列保留原操作，并允许其后没有依赖关系的文字、便签和背景设置继续提交。失败批次不会拆分；同一对象、同一设置以及图层/画框/表格等无法证明独立的操作保留顺序。确认和重试按操作 ID 定位，不能误删除队首失败草稿。图片本身只在用户手动重试时再次提交。

- 背景类型校验与前端选项一致；由旧版校验造成的 `Background type is unsupported.` 阻塞草稿会在恢复时重新排队。
- WebSocket 操作 15 秒没有确认时重新连接；快照重同步 30 秒无响应时重新连接。原操作 ID 保证重发可去重。
- `BOARD_BUSY`、限流和暂时性服务错误自动重试；不可恢复的校验错误保留本地操作并显示同步问题入口。
- 单元格临时占用使用 `SHEET_CELL_BUSY` 自动退避重试，旧服务端的同义提示也兼容；真正的单元格版本冲突仍保留草稿等待处理。暂时性错误和画布版本重同步不会提前结束单元格提交等待，也不反复弹出错误提示。
- 重同步快照不会清除尚未到期的重试退避；重复调度不缩短等待，收到提交确认后才重置退避。发送异常会自动重试，重同步请求发送失败会重连，切换画布后旧重试回调不提交新画布操作。本地重放因目标图层锁定暂停后，在收到解锁状态并通过重放检查时自动继续。
- 图片权限拒绝会暂停队列，保留失败操作及后续草稿，并立即释放编辑锁；暂停期间继续本地编辑不会续锁，也不会自动反复提交失败图片。权限检查允许使用自己的笔记图片和当前可读的共享笔记页面图片；未共享页面和已撤销的来源权限仍会拒绝，提示包含图片名称或元素 ID。旧版通用图片权限报错在恢复本地队列时尝试一次新版校验，若仍失败则保持暂停。
- 图片授权确实无法恢复时，“同步问题”中的“重新选择原图”会上传用户选定的图片，替换队列里同一失效图片的所有引用，保留其他操作及图片的位置、尺寸等修改。改过内容的操作使用新操作 ID，并先保存本地队列再继续同步；上传、本地保存失败或切换账号/画布时不会自动丢弃草稿。
- 离线或服务端不可用时保留 outbox，恢复连接后按顺序提交。IndexedDB 与 localStorage 都不可用或容量不足时，界面会提示保持页面开启并重试保存。
