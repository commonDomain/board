# 当前界面基线与架构选择

## 当前范围

本文记录当前有效的界面和架构选择，包括画笔、状态历史、画布加载与服务启动。地图使用同源隔离框架；多账号共享、登录注册全流程及真实移动设备仍需在部署环境验收。

## 画笔

- `brush-engine.js` 继续作为已存笔画和新笔画的唯一效果渲染器，保留九种笔刷和旧数据格式。
- `brush-preview.js` 负责预览调度、相机矩阵、画布清理和故障回退；`brush-preview-worker.js` 在独立线程加载同一渲染器与 Perfect Freehand。
- 预览与落笔共享采样量化、种子、压感、流量、画笔宽度和对称坐标。每次规范预览覆盖前一张，避免半透明重复叠色。
- 调度最多保留一个正在计算的请求和一个最新状态工厂，防止积压整条笔画副本。正常调度间隔至少 32 ms；Worker 错误或超时后回退，回退间隔根据实际耗时调整。
- Worker 使用视口画布并转移 ImageBitmap；主线程显示后关闭位图。取消笔画/切换画布会注销控制器，过时位图不显示。
- 代价：整笔计算仍随复杂度增长，但不逐片更改笔刷算法，避免旧笔触外观和导出结果变化。6000 点长笔画本机原生 Canvas 基准中位数约 55–133 ms；此数值不是浏览器帧耗时，复杂对称笔画可能更慢。生产 Chrome 已确认普通钢笔和水彩笔迹可绘制、保存和刷新恢复，但未执行 6000 点交互式压力测试。

## 状态与历史

- `backend/state-codec.js` 将不可变采样点与可变文档状态分开：草稿共享冻结的采样点，其余对象深拷贝；错误操作仍不能改动已提交状态。
- 使用 WeakMap 缓存采样点 JSON，替换/删除后的数组可随原状态回收；缓存字节纳入现有画布缓存预算。
- 保留 SQLite `WAL + synchronous=FULL` 与现有事务、版本检查、备份恢复格式。没有修改数据库架构，没有把尚未持久化的操作提前确认给客户端。
- 25 万点本机热缓存的复制+序列化中位耗时由约 161 ms 降为 5.37 ms；冷处理约 169 ms。基准不包含 SQLite 磁盘写入，完整状态写入仍是后续可能的瓶颈。
- `public/app/history-controller.js` 负责快照、补丁、撤销/重做、文档差异与历史预算；`public/history.js` 保留纯差异算法。
- 一笔及其对称副本使用一个实体补丁记录；其他已完成的快照操作在微任务边界压缩为字段补丁。异步操作未发生时保留其快照锚点；画布代次变化时不执行旧压缩任务。
- 历史控制器与客户端功能使用 ES 模块显式导入依赖，由 `public/app/bootstrap.js` 装配。源码目录与构建约定见 [代码维护说明](code-maintenance.md)。

## 画布加载与浏览

- 性能排序以高频浏览为先，同时保留编辑结果的即时可见性。大画布按对象、表格单元格、脑图节点、长文本和导航结果估算渲染复杂度；加载时统计一次，之后随单个对象增删改更新，避免编辑期间周期性遍历整块画布。首次显示的新节点分帧挂载，已挂载对象的编辑仍同步渲染。
- 分帧队列使用游标顺序读取，避免大队列反复移除首项造成二次方复杂度。空间索引继续负责视口裁剪，锁定、选中和正在编辑的对象保持挂载。
- 切换画布时并行读取 IndexedDB 快照/outbox 与建立 WebSocket；只有本地恢复完成后才发送 join，确保缓存 revision 和待提交操作不会被跳过。
- 没有待提交操作时，纯查看和切换不写空 outbox。完整快照写入按画布代次合并，IndexedDB 成功后不再重复把整份快照序列化到 localStorage；localStorage 仍保留小型 outbox 的同步恢复副本。
- 目录接口一次联表返回画布和所有者公开资料，避免按画布逐项查询。新账号的自动初始画布为私有。
- 服务升级仅迁移旧版本文档；搜索、空间、地图组件和资源引用派生数据按版本标记重建一次，普通启动跳过全库重建。资源容量扫描、图片回填和启用后的资源回收在监听后顺序执行；写请求仍会等待准确容量检查。

## 验证与本地环境

```powershell
npm run check
```

当前新建账号画布默认为共享。生产 Chrome 已验证：普通钢笔与水彩笔迹、智能平移/选择、画框、两图形间连线及移动后重路由、点阵与高清背景、地点搜索、地图、路线规划、内容导航搜索、工具栏收起/展开、保存及刷新恢复。控制台没有应用自身警告或错误。

仍需真实设备或独立账号验证：触摸和多指操作、窄屏系统输入法、6000 点长笔画帧时间、多账号共享授权/撤销、跨标签页登录/退出竞态。

游客人工验收顺序：九种笔刷与对称/长笔画 → 撤销重做 → 空白处平移与对象选择 → 中键/空格临时平移 → 锁定画框及跨框分组 → 连线拖拽 → 背景与漂移 → 窄屏、键盘焦点和减少动画设置。
